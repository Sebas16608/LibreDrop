LibreDrop

Open Source Commerce. Simple. Libre.

LibreDrop es una plataforma Open Source para crear tiendas en línea de forma rápida, sencilla y sin pagar licencias de software. Está licenciada bajo GNU AGPL v3.

Open Source

¿Por qué Open Source?

LibreDrop es completamente libre: cualquiera puede estudiar, modificar y compartir el proyecto sin restricciones.

  • Cualquiera puede descargar el código.
  • Puedes modificarlo.
  • Puedes redistribuirlo bajo AGPLv3.
  • Crea nuevas funcionalidades.
  • Realiza auditorías.
LibreDrop

$ cd backend
$ pip install -r requirements.txt
$ python manage.py migrate
$ python manage.py runserver

FAQ

Preguntas frecuentes

Sí. La versión Open Source de LibreDrop se distribuye bajo la licencia GNU AGPL v3 y no tiene costo de licencia. Puedes descargar el código fuente, instalarlo en tu propio servidor y usarlo sin restricciones comerciales. LibreDrop Cloud es un servicio administrado aparte, con su propio precio.

LibreDrop OSS es el proyecto de código abierto que tú instalas y administras. LibreDrop Cloud es la versión administrada: nosotros nos encargamos del hosting, las actualizaciones, las copias de seguridad y el soporte para que puedas enfocarte en vender.
